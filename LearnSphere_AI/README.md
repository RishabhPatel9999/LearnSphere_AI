# LearnSphere AI

A complete responsive static website created for **Task 3 — AI Website Generation**.

## Included
- Responsive homepage
- About section
- Services section
- Platform features
- Interactive AI Tutor demo
- Testimonials
- Contact / CTA section
- Mobile navigation
- Scroll progress bar
- Scroll reveal animations
- No backend or API required

## Run in VS Code

1. Extract/open this folder in VS Code.
2. Open `index.html` in a browser.
3. For the best development experience, install the **Live Server** extension in VS Code.
4. Right-click `index.html` → **Open with Live Server**.

## Important
The AI Tutor is a **front-end demonstration**. It uses JavaScript sample responses and does not connect to a real AI API.
